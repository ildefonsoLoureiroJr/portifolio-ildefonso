## 🎯 Sobre o Projeto
Portfólio pessoal desenvolvido para apresentar minha trajetória profissional 
e projetos como desenvolvedor FullStack em formação.

## 🚀 Tecnologias Utilizadas
- HTML5 Semântico
- CSS3 (Flexbox, Grid, Variáveis CSS)
- JavaScript (ES6+, IntersectionObserver)
- Font Awesome (ícones)

## ✨ Funcionalidades
- Design responsivo (mobile, tablet, desktop)
- Modo escuro/claro
- Navegação suave entre seções
- Menu mobile com hambúrguer
- Mega menu com dropdowns
- Destaque automático da seção ativa
